# Напоминание о замене линз

Личный сайт на PHP, HTML и CSS. Кнопка записывает текущую дату замены. Следующая замена назначается через 14 дней. Скрипт `notify.php` отправляет одно напоминание в Telegram после наступления срока, если новая замена ещё не записана. История хранится в `data/state.json`, файл создаётся автоматически.

## Что потребуется

- PHP 8.0 или новее с включённым `allow_url_fopen`.
- Веб-сервер и доступ PHP на запись в `data/`. Рекомендуемый корень сайта — **`public/`**.
- cron на сервере (или планировщик задач, который может запускать PHP каждый час).
- HTTPS, если сайт будет доступен из интернета: пароль сайта передаётся браузером через HTTP Basic.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), скопируйте токен и отправьте своему боту `/start`.
2. Откройте `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`. Найдите `message.chat.id` в ответе. Если список `result` пуст, напишите боту ещё одно сообщение и обновите страницу. Значение `chat.id` сохраните целиком, в том числе знак минуса, если он есть. Если для бота уже настроен webhook, `getUpdates` не будет работать до его отключения.
3. В `config.php` замените пароль, токен и `chat_id` своими значениями. Токен никому не отправляйте и не выкладывайте `config.php` в публичный репозиторий.
4. Настройте корень веб-сервера на папку `public/`. Если на Apache это невозможно и корень указывает на всю папку `lens-reminder/`, корневой `.htaccess` перенаправит запросы в `public/` и запретит прямой доступ к служебным файлам. Для этого на Apache должен быть включён `mod_rewrite` и разрешён `AllowOverride`. Для локальной проверки из папки проекта запустите `php -S localhost:8000 -t public` и откройте `http://localhost:8000`. Имя пользователя для входа: **`lens`**, пароль — из `config.php`.
5. После установки новой пары нажмите **«Поменял линзы»**. Это создаст первую запись и запустит отсчёт.
6. Добавьте в cron на сервере (заменив пути на свои):

   ```cron
   0 * * * * /usr/bin/php /полный/путь/lens-reminder/notify.php >> /полный/путь/lens-reminder/cron.log 2>&1
   ```

Проверка выполняется каждый час. Сообщение придёт при первой проверке после истечения 14 дней. Если сервер или cron были выключены, сообщение будет отправлено при следующем успешном запуске. Если Telegram временно недоступен, скрипт завершится с ошибкой и повторит отправку при следующей проверке.

Отправка выполняется через `file_get_contents()` с HTTPS, как в обычном обработчике формы. Если сервер не может соединиться с `api.telegram.org:443`, смена cURL на `file_get_contents()` сама по себе не решит проблему сети. Для проверки выполните `php notify.php` из папки проекта после наступления срока; файл не открывается через браузер.

Время в интерфейсе и сообщениях — московское (`Europe/Moscow`). При необходимости измените часовой пояс в `src/app.php`. Предпочтительно держать `data/`, `config.php` и `notify.php` вне корня веб-сервера. При размещении всей папки в корне Apache защита зависит от работы `.htaccess`; проверьте, что прямой запрос к `/config.php` возвращает 403. Если сайт доступен другим людям, задайте длинный уникальный пароль.
